अंक कसा तयार करायचा

दर महिन्याला ३ पायऱ्या · साधारण ५ मिनिटं

कधी करायचं? महिना संपल्यावर, पुढच्या महिन्याच्या पहिल्या आठवड्यात — म्हणजे त्या महिन्याचे सगळे लेख ब्लॉगवर आल्यानंतर.

उदाहरण : ऑगस्टचा अंक ७ सप्टेंबरनंतर तयार करायचा. तेव्हा महिन्याचा क्रमांक 2026-08 असा लिहायचा.

सुरुवातीला एकदाच — one-time

GitHub नावाच्या वेबसाईटवर स्वतःचं मोफत खातं उघडा (github.com/signup), आणि तुमचं username अमोघला कळवा. तो तुम्हाला परवानगी देईल. हे एकदाच करायचं आहे.

पायरी १ · काय प्रसिद्ध झालंय ते बघा — Preview

  1. ही लिंक उघडा : Preview a month
  2. उजवीकडे, जुन्या नोंदींच्या यादीच्या वर, एक करडं बटण दिसेल — Run workflow ▾. त्यावर क्लिक करा.
  3. एक छोटी खिडकी उघडेल. त्यात एक रिकामा चौकोन असेल. त्यात महिना लिहा — 2026-08. वरचा Branch: main तसाच राहू द्या.
  4. त्याच खिडकीतलं हिरवं Run workflow बटण दाबा.
    खिडकी बंद होईल आणि काहीच झालं नाही असं वाटेल. घाबरू नका — पान refresh करा. वर एक नवी ओळ दिसेल.
  5. ओळीपुढे पिवळं वर्तुळ फिरत असेल. साधारण १५ सेकंदांत ते हिरव्या ✓ मध्ये बदलेल. मग त्या ओळीवर क्लिक करा.
    त्या पानावरच त्या महिन्याच्या लेखांची यादी दिसेल — नाव, तारीख आणि लिंक.

यादी बघून ठरवा : सगळे लेख आलेत का? पूर्ण अंकात साधारण ५ ते ७ लेख असतात. जर फक्त २-३ दिसत असतील, तर अजून सगळे लेख ब्लॉगवर आलेले नाहीत — थोडं थांबा, आणि नंतर पुन्हा पायरी १ करा.

पायरी २ · अंक तयार करा — Build

  1. ही लिंक उघडा : Build issue
  2. तसंच उजवीकडचं Run workflow ▾ बटण दाबा. आता चार गोष्टी विचारल्या जातील :
    Month2026-08 — महिना
    Page layouttwocol — दोन स्तंभ. हेच ठेवा.
    Cover pagetitle — मुखपृष्ठावर नाव आणि महिना
    Publish…बरोबरची खूण तशीच राहू द्या
  3. हिरवं Run workflow दाबा, आणि पान refresh करा.
    यावेळी साधारण १ मिनिट लागेल. हिरवी ✓ येईपर्यंत थांबा.

काही अडलं तर — if something looks wrong

ओळीपुढे लाल ✗ आलं

काहीतरी चुकलंय. काळजी करू नका, काहीही बिघडलेलं नाही. त्या ओळीवर क्लिक करा, आणि तो स्क्रीनशॉट अमोघला पाठवा.

“No category found for this month”

त्या महिन्याचा एकही लेख अजून ब्लॉगवर आलेला नाही, किंवा महिन्याचा क्रमांक चुकला आहे. 2026-08 असा — आधी वर्ष, मग महिना — लिहिला आहे ना, ते बघा.

लेख कमी दिसतायत

ब्लॉगवरचा तो लेख त्या महिन्याच्या category मध्ये टाकलेला आहे का ते बघा. खेळघरच्या आणि सूचनांच्या पोस्ट मुद्दामच वगळल्या जातात.

चुकून चुकीचा महिना दिला
